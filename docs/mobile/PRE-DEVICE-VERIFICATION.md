# 실기기 테스트 전 정리·수정 검증

2026-10-07 KST. 실제 Android 휴대폰 테스트는 아직 실행하지 않았다.

## 저장소 정리

- 루트 README는 실제 저장소 구조와 실행·검증 경로 중심으로 정리했다.
- 초기 기획·출처·팀 기록은 `docs/project/CONCEPT.md`로 분리했다.
- 참조되지 않는 완료된 에이전트 구현 계획을 삭제했다.
- 프로토타입·운영자 화면·검증 도구·API 계약·라이선스·이미지는 실행 또는 회귀 검사에서 사용하므로 유지했다.
- `node_modules`, 빌드 결과, 개인 Firebase/지도 설정과 토큰은 Git에서 제외한다. 로컬 디스크의 설치 의존성 크기는 GitHub 저장소 크기가 아니다.

## 수정

- 동의·프로필·설정·운동 저장을 계정 단위 Firestore 트랜잭션으로 분리하여 다른 사용자의 운동 기록과 공통 메타 문서 잠금 경쟁을 줄였다.
- 기존 계정 인덱스 초기화, 보상 만료 예산 반환, 중복 요청과 계정 삭제 규칙을 검증했다.
- 늦게 도착한 서버 복구 응답이 새 운동이나 일시정지 상태를 덮어쓰는 문제를 수정했다.
- 서버에서 이미 끝난 운동을 활성 운동으로 가져오지 않는다.
- 촬영 권한·GPS·사진 봉인·업로드를 기다리는 중 계정이 바뀌면 이전 계정 작업을 중단한다.
- 최초 저장 중 중단되어 `.json.tmp`만 남은 운동/사진 기록도 찾아 복구한다.

로컬 Node는 24.14.1, Java는 17이며 프로젝트/CI 대상은 Node 22다. Android 빌드는 동일 모바일 소스를 영문 경로 체크아웃에서 실행했다. Kotlin/AGP의 한글 경로 문제를 피하기 위한 경로 선택이다. 생성된 APK와 검증 JSON은 Git 제외 `output/`에 보관한다. 개발 APK는 Metro 연결이 필요하다.

동시 저장의 수치와 범위는 [부하 검증](../api/LOAD-VERIFICATION.md)을 참고한다. 로컬 Emulator는 운영 수용량이나 실제 기기 센서 동작을 보장하지 않는다.
