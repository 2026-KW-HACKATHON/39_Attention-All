운동은 손목에서.
사진은 폰에서.

폰과 같은 운동 세션을 보고 조작하는 우이런 워치 앱.
체크포인트의 상태를 먼저 확인하고, 사진을 남길지 선택합니다.

버튼으로 체험전체 화면예외 상태

화면과 연결 요청을 체험하는 시뮬레이션입니다. 실제 폰 실행·촬영·서버 저장은 수행하지 않습니다. 종료 버튼은 1.2초 길게 누르거나 키보드 Enter / Space를 길게 누르세요.

폰 · 연결됨

위치 수집과 서버 통신은 폰이 담당합니다.

01 / 기본 플로우

준비 → 시작 → 운동 → 체크포인트 → 참여 → 운동 복귀 → 종료

체크포인트 알림 W3에서 바로 응답 → 응답 선택 → 사진 촬영 선택 W4-B → 폰 촬영 연결 W4-C → 서버 확인 → 운동 복귀
체크포인트 알림에서 아무 응답도 선택하지 않으면 10초 뒤 운동 화면으로 돌아갑니다. 사진 촬영은 선택 사항이며 촬영 중에도 운동은 계속됩니다.

02 / 연결과 복구

연결 끊김 · 폰 열기 실패 · 저장 지연 · 폰 결과 연결

같은 세션, 같은 기록

폰이 GPS·거리 계산·서버 통신을 담당하고 워치는 상태와 조작을 공유합니다. 폰에서 시작한 세션도 워치에 표시하며, 재실행 시 새 운동 대신 기존 운동을 복구합니다.

체크포인트 규칙

기존 기획 기준: 100m 접근 알림, 응답 CTA는 참여 가능한 40m 안에서 표시, 세션당 최대 3회, 같은 지점 1회, 최소 5분 간격. 40m 안에서 참여합니다. 상태 질문에 답하지 않으면 10초 뒤 운동 화면으로 복귀합니다. 실제 활성 조건과 보상은 서버 정책에 맞춰 확정합니다.

사진 연결은 참여 완료가 아닙니다

우이런 내부 카메라 요청 → 앱 안에서 촬영·업로드 → 서버 확인 → 참여 결과 순서입니다. 포인트는 실제 응답값을 표시하며 지급 대기·중복 참여는 성공 예시와 구분합니다.

연동 전에 맞출 부분

상태 응답 3종 및 사진 생략 시의 저장·보상 방식, 휴대폰 촬영 화면의 체크포인트 식별자, 화면 열기 실패 처리와 양쪽 알림 중복 방지를 합의해야 합니다. 현재 HTML은 화면 설계안입니다.
